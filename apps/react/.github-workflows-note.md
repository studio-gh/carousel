# React workspace notes

The beta app lives under `apps/react/` and is deployed only through an isolated preview until quality gates pass. The public single-file app at repository root remains the production release.

Current scripts:
- `npm run dev`
- `npm run typecheck`
- `npm run test -- --run`
- `npm run build`

The first CI bootstrap currently uses pinned direct dependencies and npm install because a lockfile cannot be generated from the local runner when the npm registry is unreachable. After the first successful remote install, commit the generated lockfile and switch CI to `npm ci`.
